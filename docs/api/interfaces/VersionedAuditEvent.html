Interface VersionedAuditEvent

Versioned audit event

This is the canonical audit event structure used throughout TealTiger. All audit events MUST include schema_version, event_type, timestamp, and correlation_id.

Security-by-default: Raw prompts and responses are NEVER included by default. Use safe_inputs and safe_outputs for redacted content metadata.
